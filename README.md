# Metro City 3D

Een speelbare low-poly 3D open-world browsergame met Three.js.

Besturing: **Z** vooruit, **S** achteruit, **Q** links, **D** rechts, pijltjestoetsen werken ook. Gebruik muis-slepen voor de camera, Shift om te sprinten en Space om te springen.

Start lokaal met `npm install` en `npm run dev`. Build met `npm run build`.
